# Convex, symmetric and transitory: growing-season climate variability and food prices in 153 countries

Replication package and manuscript for a study of how growing-season climate variability
transmits into domestic food prices.

**Headline result.** The signed temperature anomaly used throughout the weather-and-prices
literature carries a coefficient of 0.002 (s.e. 0.035) at a nine-month horizon. Its square
carries 0.057 (s.e. 0.016). Across fifteen specifications the quadratic term is significant
at five per cent in thirteen, the linear term in one. The price response to a growing season
is convex in the anomaly, symmetric in the two tails, and exhausted within about eighteen
months.

---

## Reproduce everything with one command

```bash
git clone <this-repo>
cd <this-repo>/replication
pip install -r requirements.txt
python run_all.py
```

Full run takes about 6 minutes on a laptop. `python run_all.py --fast` takes about 4.
Outputs land in `replication/results/` as plain-text tables and machine-readable CSVs.

There is nothing to configure. The two raw datasets ship with the repository in gzipped
form and are found automatically.

## Data

Two files, shipped gzipped because GitHub rejects files above 100 MB. `pandas` reads them
directly, so no manual decompression is needed.

| File | Compressed | Rows |
|---|---|---|
| `data/climate_food_monthly_estimation.csv.gz` | 14.2 MB | 56,386 |
| `data/climate_macro_annual_with_exposure.csv.gz` | 6.6 MB | 14,322 |

The monthly file combines FAO food and headline consumer price indices with crop-calendar
and growing-area weighted temperature and precipitation anomalies over each country's wheat
and rice producing regions, plus World Development Indicators lagged one year. The annual
file carries FAO production and trade series and the same macroeconomic indicators.

**Maize is excluded from the study by design.** The monthly file is read with a column
filter, so no maize variable is ever loaded; stage 1 reports the 37 columns dropped.

```bash

```

This re-reads every result file and asserts each number quoted in the manuscript prose.
It exits non-zero on any mismatch. At the current commit it reports 55 of 55 claims

to a bibliography entry.

## Design decisions that affect results

**The shock is a surprise, not a level.** Growing-season temperature anomalies are
residualised on country-by-calendar-month fixed effects and a country-specific linear
trend. This removes harvest seasonality and each country's own warming path. Because
the trend is removed, **no estimate here speaks to the price consequences of secular
warming**; the paper measures the response to variability around each country's adapted
norm.

**Leads and lags run on a complete calendar grid.** The panel is reindexed to a full
country-by-month grid before differencing, so a horizon-*h* lead is always exactly *h*
calendar months ahead even where the sample filter removes interior observations.

**Pre-trend horizons shift the control window.** At *h* < 0 the dependent variable is an
exact linear combination of the outcome lags in the control set, which makes the regression
degenerate and produces a spurious clean pre-trend. The control window is shifted back by
|*h*| at placebo horizons.

## Honest caveats, printed by the code itself

- Excluding the 2007–2009 food crisis weakens the level coefficient substantially, and it
  is insignificant when both crisis windows are dropped. The *shape* result survives both
  exclusions. Two candidate explanations (greater tail variation, tighter global markets)
  were tested and rejected.
- The financial-depth heterogeneity is not robust to excluding 2020–2022. It is reported
  as a secondary result.
- Growing-season volatility is rising significantly, but the implied contribution to food
  inflation over the sample is about 0.016 percentage points. The paper says so rather than
  projecting a larger number.

`replication/NOTES_FOR_MANUSCRIPT.md` documents six hypotheses that were tested and
discarded, with the statistic that rejected each.

## Requirements

Python 3.9 or later with numpy, pandas, scipy, scikit-learn and statsmodels. Building the
manuscript additionally needs `python-docx` and `matplotlib`. Tested on Windows 10 with
Python 3.13; paths resolve relative to the package so non-ASCII directory names are fine.
